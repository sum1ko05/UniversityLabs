## ⚙️ Как запустить проект

1. Клонировать ветку репозитория:
   ```bash
   git clone -b web https://github.com/sum1ko05/UniversityLabs.git
   cd UniversityLabs/lab9
   ```
2. ВАЖНО! Добавить в проект каталог для базы данных и .env файл и указать их в ```docker-compose.yml```
3. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
4. Открыть в браузере главную страницу:
   ```http://localhost:8080```
5. (Опционально) Запустить тесты:
   ```bash
   vendor/bin/phpunit tests
   ```

📂 Содержимое проекта

```docker-compose.yml``` — описание сервисов, необходимо подредактировать перед запуском

```.env.example``` — образец .env файла проекта. При написании .env файла обязательно заменить секреты на свои! 

```config/``` — каталог со всеми конфигурационными файлами проекта

```database/``` — каталог с базой данных. При отсутствии в проекте необходимо его создать

```public/``` — каталог со всеми файлами для демонстрации

```tests/``` — каталог с тестами

```app/``` — каталог с основным кодом приложения

```../.github/workflow/ci.yml``` — описание действий для GitHub Actions CI. Запускается для всей ветки, но на данный момент CI настроен специально под данную лабораторную работу.

✅ Результат

CI/CD pipeline настроен и выполняется на стороне GitHub Actions. Docker-контейнеры успешно поднимаются. Тесты PHPUnit автоматически проходятся как шаг CI. Ошибки легко можно посмотреть в консоли GitHub Actions, как падения на поднятии проекта, так и падения на unit-тестах.
