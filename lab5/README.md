## 📌 Описание задания

1. Научиться работать с базой данных MySQL через PHP.

2. Создать таблицу для данных формы.

3. Сохранять данные формы в базу данных.

4. Выводить данные из базы на странице.

5. Использовать классы PHP для работы с таблицей.

6. Работать с Docker контейнерами: nginx (уже есть), PHP-FPM, MySQL, Adminer.

  
Результат доступен по адресу [http://localhost:8080](http://localhost:8080).

---

## ⚙️ Как запустить проект

1. Клонировать ветку репозитория:
   ```bash
   git clone -b web https://github.com/sum1ko05/UniversityLabs.git
   cd UniversityLabs/php-composer-lab
   ```
2. Загрузить зависимости через Composer:
   ```bash
   composer update
   ```
3. ВАЖНО! Добавить в проект каталог для базы данных и .env файл и указать их в ```docker-compose.yml```
4. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
5. Открыть в браузере:
   ```http://localhost:8080```

📂 Содержимое проекта

```docker-compose.yml``` — описание сервисов, необходимо подредактировать перед запуском

```nginx/nginx.conf``` — конфигурационный файл Nginx

```composer.json``` — конфигурационный файл проекта Composer

```public/``` — каталог со всеми файлами для демонстрации

```public/classes``` — каталог с классами
