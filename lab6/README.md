## ⚙️ Как запустить проект

1. Клонировать ветку репозитория:
   ```bash
   git clone -b web https://github.com/sum1ko05/UniversityLabs.git
   cd UniversityLabs/php-composer-lab
   ```
2. Запустить контейнеры:
   ```bash
   docker compose up -d --build
   ```
3. Открыть в браузере при первом запуске для индексации:
   ```http://localhost:8080/startup_index.php```
4. После этого можно спокойно открыть в браузере главную страницу:
   ```http://localhost:8080```

📂 Содержимое проекта

```composer.json``` — описание зависимостей проекта

```public/classes/clients``` — каталог со классами клиентов и их фабрики

```public/classes/clients/MoviesApiClient.php``` — класс API клиента каталога фильмов. По умолчанию идёт обращение к топ 50 фильмов по версии IMDb. Заменить ссылку в конструкторе при реальном использовании.
